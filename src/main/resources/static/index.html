교대 패턴 관리

교대 근무 캘린더의 자동 패턴을 다시 설정할 수 있어요.

1. 시작 코드 세트 만들기 기본 제공 코드는 시작용입니다. 이름, 색상, 시간은 자유롭게 바꾸고 새 코드도 추가할 수 있어요.
2. 주간 반복 일정 만들기 요일별 기본 일정을 정하면 일반 일정 캘린더가 자동으로 채워져요.

캘린더 공유

이메일로 초대하고 보기/편집 권한을 설정하세요.

선택한 캘린더 공유할 캘린더를 확인하세요.
현재 캘린더를 소유한 사용자만 공유 권한을 관리할 수 있습니다.
사용자 초대 개별 사용자에게 보기 또는 편집 권한을 보냅니다.
공유 그룹 여러 사람을 그룹으로 묶어서 반복되는 공유 설정을 줄입니다.
현재 캘린더에 적용된 그룹 권한 선택한 캘린더에 내 공유 그룹을 연결합니다.
